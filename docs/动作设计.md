# 虚拟形象动作设计（肥鱼 · 待机 / 鞠躬 / 摇头 / 庆祝）

> 目标：让「无骨骼 2D 分层立绘 + 程序化 3D」的待机与动作符合人体工学与真实物理，
> 流畅自然、不抖、不砸、不穿模。三层渲染器（`whale-girl-layered.js` 默认、
> `whale-girl-3d.js`、`whale-girl.js` 回退）共用 `stage/motion-profiles.js` 的参数与曲线。
> 最后更新：2026-10-29。

## 1. 参考资料研究结论

- `https://ai-pose-gallery.anhao.app/` 是 **AI 姿势参考图库**：288 组人体姿势 / 1439 张
  多角度（正面、斜侧、侧面、俯视、仰视）人像参考图，中文站由 Anhao 维护；它提供的是
  **静态图片 + 元数据**（体系 / 编号 / 分类 / 姿势名 / 角度 / 图片路径），不是骨骼、
  关键帧或动作数据，站点也没有开放 API。
- `https://github.com/anhao/ai-pose-gallery-zh` 是它的镜像 + 汉化静态画廊：`index.html`
  + `scripts/*.py`（下载/翻译/校验）以 **MIT** 开源；但 `img/`、`thumbs/`、`data/pose*.json`
  **版权归原作者（ギア）所有、明确不得商用**，MIT 不覆盖素材。
- 结论：**不能直接用于本项目**。① 数据是图片，无法驱动无骨骼 2D 贴片或程序化 3D；
  ② 素材许可禁止商用，而本仓库无 LICENSE、用于直播；③ 体积 637MB，且含成人向分类。
  因此只作为「姿态观感」的人工参考，实际动作全部自研；本仓库未下载/引用任何其素材。
- OpenDesign：本机 `Open Design.exe` 在运行，但未安装 `prebundled/daemon/daemon-cli.mjs`，
  daemon 端口 59165/59179 未监听，`od` 命令不存在；历史记录还表明账号未登录/媒体 key 未配置
  → **不可用**，未消耗任何额度，未生成图片。
- 提炼并落地的人体工学/物理原则：呼吸节律、重心转移与关节链延迟、次级运动（跟随/滞后/
  幅度衰减）、弹簧-阻尼收势、眨眼节律、动作预备-主动作-保持-回收。

## 2. 模块与参数

`stage/motion-profiles.js`（零依赖、纯函数 + 常量，ES module，可被三层 import）提供：

| 导出 | 作用 |
| --- | --- |
| `MOTION` | 全部参数总表（呼吸、重心、眨眼、待机动作、头部、2D 姿态、鞠躬、摇头、弹跳、口型、3D 增益） |
| `breathAt(t)` | 非对称呼吸曲线：周期 4.4s（≈13.6 次/分），吸气 42%、呼气 58%，两端导数为 0 |
| `weightAt(t)` | 重心转移：9.6s 主周期 + 15.3s 次周期；骨盆 ±2.4 sprite px，胸腔反向代偿 −0.42、滞后 0.42rad，头部再滞后 0.78rad、只留 0.16 残余 |
| `BlinkScheduler` / `blinkCurve` | 不规律眨眼：间隔 2.2–6.8s 偏斜分布，偶尔提前/走神/连眨；闭合 40%（~64ms）、张开 60%（~96ms） |
| `idlePose(kind,p,...)` | 张望/歪头/点头/哼歌/轻晃/连眨：梯形包络（smootherstep），张望带反向预备 |
| `bowCurve` / `bowPose` | 预备(−0.07) → 下落（smootherstep）→ 保持（2Hz 微呼吸，两端为 0）→ 回收（先微沉再起身） |
| `shakeGate` / `shakeEnvelope` | 难过摇头只占前 1.15s：`sin(πp)^0.65·(1−0.45p)`，约两下后归零 |
| `hopPose` | 下蹲预备 → 抛物线腾空（重力正确、顶点最高）→ 落地压缩 → 阻尼收住 |
| `springStep` / `DampedFollower` | 二/一阶阻尼解析解，任意 dt 稳定；头部跟随用 ζ=0.78 的欠阻尼弹簧，有轻微过冲后收住 |
| `clampTilt` | 头部倾斜硬限幅 ±0.095，防止发梢/下巴撕开脖子 |

参数集中、无散落魔法数；渲染器只读参数与纯函数，**不新增依赖、不改接口契约**
（`setMode/setMouth/setPalette/celebrate/start` + 可选 `bow()/shakeHead()` 全部保留）。

## 3. 原则如何落地

### 3.1 待机 idle
- **呼吸**：胸腔横向/纵向缩放 ±0.22% / ±0.42%，整体上浮与头部延迟起伏；
  非对称呼吸曲线避免「正弦机械感」。
- **重心转移**：骨盆先动 → 胸腔延迟反向代偿 → 头部再延迟。2D 用
  「整图平移（骨盆）+ 绕髋剪切（胸腔相对骨盆）+ 头部额外延迟位移」表达，髋部铰链固定；
  头部横向因此基本稳定（人体工学：头部保持在支撑面之上）。
- **张望/歪头**：缓入-保持-缓出（smootherstep），张望先向反方向预备 18% 再转；
  不再用线性摆或整头斜切。
- **眨眼**：不规律间隔 + 偶发连眨；闭眼贴片整像素覆盖，闭眼不半透明（避免透出虹膜）。
- **抗抖**：周期量频率 ≤2Hz（呼吸 0.23Hz、重心 0.10Hz、头部微晃 0.13Hz、摇头 1.7Hz）；
  待机动作目标用一阶指数平滑（无过冲），峰值每帧变化 <0.4px。
- 被 `speaking/singing/thinking` 或动作占用时，待机小动作让位（目标归零），
  但呼吸/重心这类姿势层保留。

### 3.2 鞠躬 bow（礼物）
- 语法：**预备**（轻微起身 7%）→ **主动作**（smootherstep 下落，峰值速度在中段）→
  **保持**（2Hz 微呼吸波纹，两端为 0）→ **回收**（先微沉再起身）。
- 头部比身体晚半步：弹簧 ζ=0.78、ω=11，峰值滞后 2–3 帧，回收有轻微过冲后收住。
- 重心下沉 + 体积补偿：整体下沉 10 canvas px、竖压 ≤3.5%、横扩 1%；
  2D 上还叠加头部前倾 0.052rad + 下沉 40 sprite px，**不出现硬切/砸下去**。
- 次级运动：尾巴反向轻摆（×−0.30 尾幅）、头发/侧发/呆毛滞后跟随（3D）。
- 3D 版本：`body.rotation.x = 0.12·bend`、`root.y −= 0.035·bend`、手臂 +0.10、头 nod 0.34。

### 3.3 摇头 shakeHead（点歌未找到）
- 阻尼包络 `actionEnv`；摇头只在前 1.15s 摆两下（正弦包络，末尾归零），之后停在无奈表情。
- 头部做**刚体**滚转 ±0.036rad + 平移 0.8 sprite px（不做整头横向剪切/切片投影，
  避免脸被拉斜）；躯干反向轻带 0.004rad；3D 对应 head yaw ±0.24、roll 0.012。
- 摇头期间待机倾斜/摆动按 0.85 衰减（`sadEnv`），不会叠加出抽搐。

### 3.4 庆祝 celebrate
- 下蹲（16%）→ 抛物线腾空（0.16–0.78，`y=4u(1−u)`，顶点最高）→ 落地压缩 5% → 阻尼收住；
- 呼吸缩放与弹跳缩放相乘，落地后 1.35s 内回到静止（settleRange=0px）。

### 3.5 约束保持
- 尾摆接缝位移为 0：尾根以上剪切在 y=760（尾根）处恰为 0；尾段 48 条横带
  `dx = shear(t0) + fin·(kk/span)²`，接缝行同一位移，无台阶。
- 头部倾斜 ±0.095 限幅（三层统一走 `clampTilt`）。
- 嘴部贴片仍裁剪在自身框内（本次未改动该逻辑）。
- 待机动作在 `mode!=='idle'` 或 bow/sad 期间让位。

### 3.6 性能
- 无每帧大对象分配：参数对象复用；剪切/缩放只是 canvas transform；
  尾段仍是 48 次 `drawImage`（与改前一致）。
- 3D 只改节点变换，无新增 mesh/材质/光源；新增状态均为标量或小对象。

## 4. 验证与量测（1280×720，确定性 30fps，无头 Chrome + CDP）

方法：冻结 `requestAnimationFrame`，用假时钟手动 `update/draw`（60Hz 物理、30fps 出帧）；
关掉背景/气泡/光晕后按 alpha 剪影量测逐行位移与头部质心；抓帧拼图见下。

- **node --check**：`motion-profiles.js` / `whale-girl-layered.js` / `whale-girl-3d.js` /
  `whale-girl.js` 全部通过；`npm test`（smoke 18 + http 29 断言）通过。
- **鞠躬**：峰值 bend 1.01（t=0.967s）；预备最小值 −0.07（有预备）；
  每帧最大步长 0.0985，其中前 1/4 段最大 0.0429 → 缓入；末帧 0.0033 已收住；
  头部峰值滞后 2 帧；头顶下沉 55px、范围 59px，无跳变。
- **摇头**：1.2s 内 4 次过零（≈2 个来回），波幅 0.668；1.3s 后 `sadWave=0`；
  头部倾斜峰值 0.0244rad ≪ 0.095 限幅。
- **待机**：呼吸 signed 范围 2、头部上下 4px；骨盆 ±2.34px、胸腔 ±0.99px（延迟反向），
  头部倾斜峰值 0.0252rad；逐帧逐像素复测头部质心最大单帧位移 **0.40px**、8s 内范围 16.5px
  （慢速重心转移，无高频抖动）。
- **接缝**：尾尖摆幅 27.07px（min −14.27 / max +14.29）；接缝行及其上下的位移中位数
  body −3.5px、seam −2.5px、tail −3.0px，**seamVsBody=1px、tailVsBody=0.5px**；
  5 行中值滤波后逐行最大跳变 **2px**（原始轮廓在近水平边缘处有 17.5px 离群，属量测伪差）。
- **眨眼**：16s 事件间隔 `[3.73, 0.40(连眨), 6.74, 1.45]`，均值 3.97s、标准差 2.17s → 不规律。
- **庆祝**：头顶升降 52px，1.35s 后静止。
- **三层**：默认 `dataset.avatar='2d'`；`?avatar=3d`（SwiftShader）与 `?avatar=canvas`
  均加载成功、各步进 105 帧无 NaN / 无异常，鞠躬同时驱动 3D head/root。

## 5. 已知限制

1. 2D 分层立绘是单张正面图，无法真正转头/转身；张望只做小幅平移+倾斜+刚体旋转，
   幅度刻意保守（与项目「不要整头变形」的既定教训一致）。
2. 鞠躬的「膝盖/髋部代偿」在 2D 上只能表达为整体下沉 + 竖向压缩 + 上身前倾，
   不是真实关节链；3D 为程序化节点近似。
3. 待机抓帧 JSON 中 `idle.maxCxStep=8.57` 是某一采样帧的量测伪差：逐帧复测为 0.40px，
   以复测为准（见报告）。
4. 未做长时（>1h）运行稳定性与 GPU 占用回归；未改动打包/配置/接口。
5. 未使用 ai-pose-gallery / OpenDesign 的任何素材（许可/可用性原因）。
