# 真实直播接入指南（抖音直播伴侣 + 真实弹幕/礼物 + 真实 token）

> 适用：`A:\project\aizb`（大肥鱼直播）。本文是「从 demo 到真实开播」的完整操作手册。
> 三条链路互相独立，可分开调试：
> **① 画面 + 声音** → 抖音直播伴侣窗口捕获 / OBS
> **② 真实弹幕 + 礼物** → `scripts/douyin-collector.js`（无头 Chrome 观察直播间 → POST 本机 `/ingest`）
> **③ 真实 LLM + token 计量** → 项目根目录 `.env`（不入 Git）

---

## 0. 先决条件

- Node.js 22+（本机 24 已验证）、Chrome 或 Edge
- 一台能开抖音直播的账号 + 抖音直播伴侣（Windows）
- LLM API Key（DeepSeek / 任意 OpenAI 兼容服务）
- 可选：VB-Audio Virtual Cable（把直播声音单独路由给直播伴侣）

## 1. 配置 API Key（`.env`，不会上传 GitHub）

### 1.1 填在哪

项目根目录的 **`.env`**（和 `package.json` 同级）：

```dotenv
# ── LLM（必填）────────────────────────────────
LLM_API_KEY=sk-你的真实key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
# 可选：温度 / 单次最大 token
# LLM_TEMPERATURE=0.95
# LLM_MAX_TOKENS=120

# ── TTS ──────────────────────────────────────
TTS_PROVIDER=edge
TTS_VOICE=zh-CN-XiaoxiaoNeural

# ── 弹幕接入 ─────────────────────────────────
# 外部转发器/采集器调用 /ingest 用的 token，务必改成随机长串
INGEST_TOKEN=请改成随机长串

# ── 服务端口（一般不用改）────────────────────
# SERVER_PORT=17890
```

- `.env` 已在 `.gitignore` 中（`.env`、`.env.*` 全部忽略，只保留 `.env.example`），**不会被提交到 GitHub**。
- 首次使用可复制模板：`copy .env.example .env`，然后填入 `LLM_API_KEY`。
- 优先级：**进程环境变量 > 项目根 `.env` > 用户数据目录 `.env` > `data/config.json`**。所以 `.env` 写了的项会覆盖控制台里保存的配置，且 `.env` 里的 Key **不会**被写进 `data/config.json`。
- 改完 `.env` 需要**重启服务**（`.env` 只在启动时读取）：关掉服务进程重新启动即可。

### 1.2 验证生效

打开控制台 `/admin/`，「运行状态」里应显示：

- 顶部胶囊：**LLM 模式**（不再是「Echo 模式（未配置 Key）」）
- **LLM 密钥：`.env`（已读取）**
- 说话一次后，「今日数据」的 token 会来自 DeepSeek 返回的真实 `usage`

命令行验证：

```powershell
Invoke-RestMethod http://127.0.0.1:17890/api/state | Select-Object -ExpandProperty llm
# 期望：{ status = { mode: "llm"; keySource: "env"; configured: true; ... } }
```

### 1.3 真实 token 与成本

- token 数不再是估算：`brain` 请求带 `stream_options.include_usage`，直接统计供应商返回的 `prompt_tokens` / `completion_tokens`。
- 成本按 `data/config.json` 的 `metering` 计算：

```json
"metering": {
  "inputPricePerM": 2,
  "outputPricePerM": 8,
  "ttsPricePer1kChars": 0,
  "displayMultiplier": 1
}
```

  DeepSeek 按缓存未命中价约为 输入 ¥2/百万、输出 ¥8/百万（以官网实时价格为准，改了价目表这里的数字也要改）。Edge TTS 免费，把 `ttsPricePer1kChars` 设为 `0` 更真实；`displayMultiplier` 只改展示数字、不影响记账。
- 核对口径：控制台「今日数据」 vs 供应商后台账单。差额来源主要是：TTS 字数、缓存命中（DeepSeek 缓存命中更便宜，这里按未命中算）、`displayMultiplier`。

## 2. 画面：浏览器舞台 → 抖音直播伴侣

本机 Electron 版受 Nahimic 注入影响会白屏（见 `AGENTS.md` §3），所以用**浏览器模式**跑画面，效果一致（1280×720 无边框感由 F11 提供）。

```powershell
cd A:\project\aizb
node scripts/dev-server.js            # 终端 1：本地服务
# 终端 2（或双击 _analysis\start-browser-mode.cmd）：
& 'C:\Program Files\Google\Chrome\Application\chrome.exe' --app=http://127.0.0.1:17890/stage/ --window-size=1280,720 --window-position=0,0 --autoplay-policy=no-user-gesture-required --user-data-dir=A:\project\aizb\.tmp\chrome-profile
```

- 舞台窗口按 **F11 全屏**（去掉标题栏；直播伴侣窗口捕获默认只取客户区，但全屏更保险）。
- 抖音直播伴侣 →
  - 「添加素材」→ **窗口捕获** → 选 `大肥鱼直播`（或 Chrome 窗口）→ 分辨率 **1280×720、30fps**，与舞台一致；
  - 若画面有黑边/偏移，用素材的「裁剪」对齐。
- 分辨率/帧率在 `data/config.json` 的 `stage.width/height/fps`（改后重启；舞台页面固定 1280×720 基准布局，等比缩放）。

## 3. 声音：系统声音 + 虚拟声卡

直播伴侣默认「麦克风」采集，直接选系统声音会连同游戏/系统提示音一起出去。推荐路由：

1. 安装 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)；
2. Windows 声音设置 → 输出设备改成 **CABLE Input**（或把 Chrome 单独输出到 CABLE Input）；
3. 直播伴侣 → 麦克风 → 选 **CABLE Output**；
4. 自己想听：CABLE Output → 属性 →「侦听此设备」→ 选真实耳机；
5. 舞台页音量由 `audio.js` 内部总线控制（TTS 0.9、BGM 0.24，播报时 BGM duck 到 0.05），不需要系统音量拉满。

> 虚拟机的坑：不要用 RDP 看舞台（会切会话导致窗口捕获黑屏），用 VNC 或 `tscon %sessionname% /dest:console` 切回控制台。

## 4. 真实弹幕 + 礼物：抖音采集器

> 抖音没有公开的观众弹幕接口。本项目用**无头 Chrome 打开你的直播间、观察聊天区 DOM** 的方式采集，属于非官方方案；平台改版/风控可能导致失效，请自行评估合规风险（见 §7）。

### 4.1 获取房间号

浏览器打开你的直播间，地址形如：

```
https://live.douyin.com/1234567890123
```

末尾那串数字就是房间号（也支持直接填 `1234567890123`）。

### 4.2 两种启动方式

**方式 A：控制台一键（推荐）**

- 打开 `/admin/` → 「抖音真实直播」卡片 → 粘贴直播间地址或房间号 → **保存并连接**；
- 卡片下方会显示采集器状态：`已连接 / 未启动 / 未连接 · 原因`、已抓事件数、最近事件时间；
- 「事件注入」里的弹幕源选择框会显示 `douyin`，可随时切回模拟弹幕。

**方式 B：命令行单独跑（便于调试）**

```powershell
# 只打印、不写入（调试选择器用）
node scripts/douyin-collector.js --room 1234567890123 --ingest http://127.0.0.1:17890 --probe --verbose

# 正式上报（token 用 .env 里的 INGEST_TOKEN 或 data/config.json 的 ingest.token）
node scripts/douyin-collector.js --room 1234567890123 --ingest http://127.0.0.1:17890 --token 你的ingest_token
```

- `--headless=false` 会弹出可见的 Chrome，方便你确认直播间是否正确加载；
- 采集器日志：`EVENT {...}`（每条事件）、`STATUS {...}`（每 60 秒：连接状态/事件数/房间号）；
- 采集到的事件会走 `POST /ingest`（`x-ingest-token` 鉴权）进入导演队列：弹幕会被回复、礼物会打断播报、含「点歌/想听」的弹幕会自动转点歌。

### 4.3 验证链路

1. 自己直播间发一条弹幕「测试一下」——舞台弹幕墙应出现该条，肥鱼开始回复（若被冷却/概率过滤，多发几条）；
2. 控制台「运行状态 → 弹幕源」显示 `douyin`，「已抓事件」递增；
3. 送一个小礼物——舞台出现礼物横幅 + 爱心 + 播报感谢；
4. 点歌——`data/music/` 有对应 mp3 时会入队播放。

### 4.4 平台改版怎么办

选择器集中在 **`scripts/douyin-selectors.json`**，不用改代码。用 `--probe --verbose` 看抓到什么；必要时用 `--headless=false` 打开页面，F12 检查聊天区 DOM 的 class/结构，更新 json 里的候选选择器后重试。

### 4.5 已知限制

- 需要能匿名/正常打开直播间；遇到**登录弹窗、验证码、滑块**时采集器抓不到数据（可在 `--headless=false` 手动登录一次，profile 会保留在临时目录，但重启采集器会新建 profile，需重新登录）；
- **未登录时昵称会被平台脱敏**（如 `子*****`），采集器如实上报，不影响用户冷却/去重；
- **礼物**：真实房间实测窗口内没人送礼，礼物 DOM 结构未在真实页面确认；采集器已用本地 mock 验证礼物解析，并在主进程侧加了「送出/赠送 xxx ×N」文案兜底（识别到就转成 gift 并触发感谢）。若你的直播间礼物不触发，用
  `node scripts/douyin-collector.js --room <id> --probe --dump-dom _analysis/dy.html --duration 45`
  抓 `_analysis/dy.html.diag.json` 里的 samples，把真实 class 填进 `scripts/douyin-selectors.json` 的 `giftItem/giftName/giftCount`；
- 礼物「价值」网页端拿不到，按 `scripts/douyin-selectors.json` 的 `giftValues` 映射估算，未映射的计 0；仅供节目效果；
- 视频画面上的滚动弹幕是 canvas 绘制、DOM 取不到；采集器取右侧聊天列表（实测内容一致），极端情况下虚拟列表滚动可能漏采；
- 非官方接口，平台规则/风控可能使其失效或带来账号风险；
- 采集器默认无头运行，会占用一个 Chrome 进程和几百 MB 内存。

## 5. 无人值守 / 稳定性

- 舞台心跳看门狗：12 秒无心跳自动重载舞台（每小时最多 6 次）；
- 采集器由主进程托管：异常退出后 5 秒自动重启（`douyin.restartDelaySec` 可调）；
- 日志：`data/logs/app-YYYY-MM-DD.log`，保留 7 天；
- 开机自启：打包版可设 `app.autoStart`；浏览器模式可把 `_analysis\start-browser-mode.cmd` 放进启动目录；
- 电源：电源计划设为从不睡眠、从不关屏（Electron 版还会开 `powerSaveBlocker`）。

## 7. 合规提醒（必读）

- 抖音对「无人直播/挂机直播」有治理规则；**AI 虚拟形象直播需按平台要求报备**，并对 AI 生成内容做显著标识（舞台左上角已有「AI 虚拟形象 · 本直播间画面与语音由 AI 生成」，但标识不等于豁免）。
- 采集真实弹幕/礼物属于**非官方接口**，可能违反平台协议；建议优先使用平台官方开放能力或授权的第三方工具，风险自负。
- BGM 必须拥有直播/信息网络传播权；`data/music/` 里的 mp3 请自行确认授权。
- 不要做「送礼物就做某个动作/说某句话」的诱导性玩法；礼物话术保持感谢即可。
- 仓库无 LICENSE，二次分发/商用需作者许可。

## 8. 故障排查

| 现象 | 排查 |
| --- | --- |
| 控制台仍显示「Echo 模式」 | `.env` 里 `LLM_API_KEY` 是否为空/带引号错误；改完是否**重启**了服务；`/api/state` 的 `llm.status.keySource` 是什么 |
| token 不涨 / 涨得离谱 | 检查 `llm.baseURL`/`model` 是否正确；看 `data/logs` 是否有 LLM 4xx；`metering` 单价是否按供应商改过 |
| 采集器「未连接」 | 房间号是否正确、直播间是否在播；`--headless=false --probe --verbose` 看页面是否被登录/验证码拦；网络能否访问 `live.douyin.com` |
| 抓到 0 事件 | 平台改版导致选择器失效 → 更新 `scripts/douyin-selectors.json`；或房间聊天区未加载 |
| 有弹幕但肥鱼不回复 | 行为配置：回复概率 0.5、用户冷却 25s、去重 60s、夜间降频 0.08；或已暂停自动回复 |
| 舞台白屏 | 本机 Electron 被 Nahimic 影响，用浏览器模式；或按 `AGENTS.md` §3 处理 |
| 直播伴侣捕获黑屏 | 别用 RDP；确认窗口在可见桌面、分辨率 1280×720 |
| 没有声音 | 虚拟声卡路由是否指向 CABLE Output；Chrome 是否被静音；`tts.provider` 是否为 none |
